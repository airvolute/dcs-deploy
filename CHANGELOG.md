# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/)
and this project adheres to [Semantic Versioning](http://semver.org/).

## v0.3.1 (2026-09-09)

### Changed:
    - dcs_deploy.py - added support for Jetpack 6.2.3
    - config_db.json - added support for Jetpack 6.2.3
    - compatible files - added support for Jetpack 6.2.3
    - README - removed chagenlog lines from README and added to CHANGELOG.

## v0.3.0 (2026-09-08)

### Added:
    - Created this changelog.

### Changed:
    - readme.md - detect jetson version.

## 0.2.0 (27 May 2026)

### Added
    - Added driver support for Framos cameras.
    - Added driver support for Arducam Jetvariety cameras.
    - Added Wireguard module into kernel.
    - Added DT Overlays for Stribog, Patron FPV, Internal FMU switch.
### Removed
    - Removed cvb eeprom dependency.

## 0.1.7 (16 Feb 2026)

### Added
    - Added Real Time Clock support DS1388 for DCS2.Pilot rev.2 board.

## 0.1.4 (8 Aug 2025)

### Changed
    - DCS 1.2 Support.
    - Super modes added.

## 0.1.2 (17 Jul 2025)

### Added
    - Added SPI communication support for the TPM 2.0 ATTPM20P on DCS2.Pilot rev.2 board.

## 0.1.0 (10 Jun 2025)

### Added
    - Added driver support for IMU BMI088.
